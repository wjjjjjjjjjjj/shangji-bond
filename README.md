# 档案商机网站

面向公众的档案信息化采购公告、采购意向、采购需求和更正公告索引，无需注册或登录。

## 数据与边界

数据来自现有任务“档案项目采购公告日报”生成的 Markdown 日报。当前整理 17 份日报，按公告 URL 去重得到 44 条记录；剔除 18 条结果类或标题不相关记录。历史数据当前没有可识别的采购意向，采购意向分类为空是有效结果，不填充虚构案例。

保留原始十类字段及摘要、相关度、收录日期。历史版本曾把“地区”字段错误设为统一地区，因此只采用明确的“省份”字段；不依据客户名称擅自补全省份。更正公告独立保留；同一项目的多篇公告不计为多个唯一项目，页面计量单位统一为“公告”。预算仅在单一金额和单位无歧义时换算为万元，详情保留原文。未识别截止日期不等同于仍可报名；截止日期状态按北京时间计算，日期精度不作分钟级开放状态推断。

仅导出白名单字段。钉钉地址、凭据、个人账户信息、采集脚本配置和去重数据库不进入公开目录。摘要当文本渲染，外链只允许 HTTP(S)。拒绝机器人和包含 access_token 的链接。公告可访问性记录源于日报，并非本网站实时核验。

## 更新

项目目录：`D:\工作\21codex project\项目探索\archive-opportunities`。

每日任务仍在北京时间 17:00 运行。采集程序、钉钉推送和发送去重状态保持原有职责；日报成功产生后运行：

```
python scripts/export-data.py
node --check dist/app.js
python scripts/validate-data.py
python scripts/publish-github.py
```

导出程序以只读方式扫描现有日报目录，合并历史与最新公告，原子写入 `dist/data.json`。可通过 `--source` 指定其他日报目录；`--output` 仅供验证副本使用。导出不会写入钉钉发送状态。

网站现由公开 GitHub 仓库 `wjjjjjjjjjjj/shangji-bond` 的 GitHub Pages 提供服务，绑定域名 `https://shangji.bond`。日报成功后，定时任务运行 `scripts/publish-github.py`，只通过 GitHub API 同步 `dist` 中的公开静态文件和 `data.json`，并检查 Pages 部署状态。脚本按文件内容去重，兼容 Windows 换行，不把令牌、Webhook 或本地凭据写入提交。无需新建第二个定时任务；网站部署成功才可报告更新成功，钉钉成功和网站成功分别检查。

采集失败时不生成空数据覆盖网站；保留历史记录。近期没有日报时页面显示历史数据提示，不将采集失败解释为没有新增。成功采集且当日无新增的日报仍可更新收录时间。钉钉失败但日报已成功生成时，允许网站正常更新，并独立报告钉钉失败。

## 本地预览与验证

```
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

检查数据结构、URL 唯一性、类型、异常预算、原文链接和静态资源路径；另有 Node 无浏览器交互逻辑检查。未请求浏览器视觉测试。可选 WebMCP 接口 `filter_archive_notices` 使用页面同一筛选状态；当前环境没有进行真实浏览器 WebMCP 合约验证，不影响普通访客使用。

这是静态网站，记录随定时任务重新发布。网页本身不会从用户电脑直接读取本地文件。自动更新依赖原有定时任务可运行、公开来源可访问和 GitHub Pages 发布链路有效；不是云端独立爬虫。
